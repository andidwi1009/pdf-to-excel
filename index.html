PDF Mutasi BCA ke Excel

Unggah satu atau beberapa e-statement Rekening Tahapan BCA (PDF), lalu unduh hasilnya dalam Excel.

File diproses sepenuhnya di browser kamu. Tidak ada yang dikirim ke server.

Hasil

Setiap file dicocokkan dengan ringkasan di halaman terakhir PDF (jumlah transaksi, total CR dan DB, saldo akhir) dan dengan saldo berjalan di sepanjang mutasi. Kalau ada yang tidak cocok, file ditandai "Perlu dicek" dan detailnya bisa dibuka. Khusus format e-statement BCA berteks; PDF hasil scan atau foto tidak didukung.
